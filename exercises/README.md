# Exercises

Problem first, then a starter that **compiles**, then a solution in a separate tree.

```text
exercises/<topic>/<slug>/
  README.md          # overview + how to build
  prompt.md          # the problem (no solution spoilers)
  starter/           # compiles; may be incomplete on purpose
  solution/          # the worked answer
```

`starter/` must compile. Keep spoilers out of `prompt.md` and the leaf README except for a pointer to `solution/`.
