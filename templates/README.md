# Templates

**Copy-out** starters for real projects. They are **not** built by this repo’s superbuild.

| Planned id | Purpose |
|---|---|
| `catalog-entry` | Shape used when adding a tutorial/example/how-to (in-tree recipe) |
| `app` | CMake application + tests + sanitizers |
| `header-only-lib` | Header-only library layout |
| `pybind11-extension` | Optional, later |

`catalog-entry` is the only template that exists today. It is the cookie for [CONTRIBUTING.md](../CONTRIBUTING.md), not a user-facing application skeleton.
