# Catalog-entry cookie

Copy this folder when adding a **tutorial**, **how-to**, **example**, or the `starter/` / `solution/` of an **exercise**. Replace `CHANGE_ME` and the `id` markers. See [CONTRIBUTING.md](../../CONTRIBUTING.md).

```text
# tutorial
cp -R templates/catalog-entry tutorials/NN-slug

# how-to
cp -R templates/catalog-entry how-to/slug

# example
cp -R templates/catalog-entry examples/<topic>/slug

# exercise
mkdir -p exercises/<topic>/slug
cp -R templates/catalog-entry exercises/<topic>/slug/starter
cp -R templates/catalog-entry exercises/<topic>/slug/solution
# then add prompt.md
```
